# workbuddy-ai-interview-everyday

每日 AI 面试题（AI Agent 方向）自动归档仓库。

## 目录约定

- `YYYY-MM-DD.md`：当日题目全文，包含【方向】【题目及项目背景】【答案详解】【来源平台】四段结构。

## 提交约定

- 每日仅提交当天新增的 Markdown 文件，不提交 HTML 及其他中间产物；
- 提交信息格式：`docs: 每日AI面试题 YYYY-MM-DD · 方向简称`
  例：`docs: 每日AI面试题 2026-11-26 · AI Infra 大模型高效微调与对齐`

## 来源

题目来自牛客网、掘金、知乎、CSDN、InfoQ、力扣、CodeFun2000、面试鸭、JavaGuide、微信公众号、脉脉等公开平台的面经与题解，每篇文末均附可访问的原始链接。
